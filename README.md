### Проекты

| Проект | О чём | Стек |
|---|---|---|
| **[LogisticsWeb](https://github.com/vlad200zel/Logistic-web)** | Планирование доставки с оптимизацией маршрута **по прибыли**, а не по расстоянию: база клиентов, карта, расчёт доходов и расходов по каждому участку | .NET 8 · Razor Pages · Leaflet · OSRM |

**LogisticsWeb** — учебный проект, сделанный целиком: модель данных и JSON-хранилище, CRUD-интерфейс с автодополнением адресов, матрица дорожных расстояний из OSRM, поиск самой выгодной комбинации остановок (DFS + Дейкстра) и визуализация маршрута на карте. В README проекта — описание, скриншоты, инструкция пользователя и разбор архитектуры.

### Что умею по факту

- проектировать данные и писать репозитории за интерфейсом, чтобы хранилище можно было заменить;
- строить страницы на Razor Pages с серверной логикой и клиентским JS без фреймворков;
- работать с внешними API (OSRM) и картами (Leaflet + OpenStreetMap);
- реализовывать алгоритмы на графах и перебор с оценкой результата по критерию;
- доводить проект до состояния, в котором его можно запустить одной командой `dotnet run`.
